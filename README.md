# منصّة الشيخ حسين الشعار — صَولَةُ الحَقِّ وَقَاهِرُ أَهْلِ البِدَع

منصّة ويب فخمة ذات طابع ملكيّ إسلاميّ تراثيّ (Modern Dark Royal Islamic UI/UX) لعرض
**منظومة الشيخ حسين الشعار** كاملةً: ٧٧ بيتًا (٥٨٧ – ٦٦٣) موزّعة على **خمسة فصول**.

> موقع ثابت (Static) بلا أي اعتماديات تشغيلية: HTML + CSS + JavaScript وحدات (ES Modules)،
> مع خطوطٍ عربية مُستضافة ذاتيًّا، وثلاث مقطوعاتٍ صوتية مُركّبة خصيصًا للمنصّة.

---

## ١) المزايا الرئيسية

| الميزة | الوصف | مكان التنفيذ |
| --- | --- | --- |
| **بحث فوري** | بحث لحظيّ في الأبيات الـ٧٧ مع تطبيعٍ عربي كامل (تجاهل التشكيل والهمزات وأشكال الألف/الياء/التاء المربوطة والأرقام العربية-الهندية)، تظليل النتائج في النصّ الأصلي، تنقّل بلوحة المفاتيح، ومرشّح بالفصول | `assets/js/search.js` |
| **صانع بطاقات الاقتباس** | توليد بطاقة PNG عالية الدقة (١٠٨٠×١٠٨٠ / ١٦٠٠×٩٠٠ / ١٠٨٠×١٩٢٠) بهويّة ثلاث أنماط (ملكيّة داكنة، زجاجيّة، عاجيّة)، مع إطار ذهبي وزخارف عربية واسم الشيخ وتذييل الموقع | `assets/js/quote.js` |
| **مشغّل إلقاء الأبيات** | مشغّل عائم أسفل الشاشة يُلقي الأبيات الـ٧٧ بيتًا بيتًا صوتيًّا **مع إضاءة البيت والشطر المقروء حاليًّا**، وتتبّع تلقائي للتمرير، وشريط موضع قابل للسحب، وقائمة بدء من أيّ فصل. **بلا ملفات صوتية ولا موسيقى إطلاقًا** | `assets/js/player.js` + `assets/js/speech.js` |
| **مفضّلة وتحفّظ محلي** | نجوم لكل بيت، قسم مفضّلة كامل، مرشّح لعرض المفضّلة فقط، وحفظ النمط/الصوت/المفضّلة في `localStorage` | `assets/js/state.js` |
| **النمط الملكي / الورقي** | تبديل كامل لوحة الألوان (٠بسيديان + ذهب ⇄ عاجيّ ورقيّ) عبر متغيّرات CSS، مع احترام تفضيل النظام | `assets/css/tokens.css` |
| **تجاوب كامل** | من ٣٢٠px حتى الشاشات العريضة، مع دعم الاتجاه RTL، وأمان الوصول (تنقّل لوحة المفاتيح، ARIA، تركيز محصور في النوافذ) | `assets/css/components.css` |
| **نسخة طباعة** | صفحة طباعة منسَّقة لإخراج المنظومة كاملة على ورقٍ أبيض بترويسات فصولٍ منفصلة | `assets/css/print.css` |
| **إضافات** | نطق بيتٍ مفرد، زرّ بيتٍ عشوائي، شريط تقدّم القراءة، عدّاد نتائج، تنبيهات، مشاركة أصليّة (Web Share)، وروابط مباشرة للأبيات `#v-587` | متعدّد |

### المقتضيات التقنية
- لا إطار عمل ولا خطوة بناء — يعمل بفتح `index.html` (يُفضّل عبر خادم محلي لتشغيل الوحدات).
- الخطوط: Aref Ruqaa (العناوين الكبرى) · Amiri (الاقتباسات) · Noto Naskh Arabic (الأبيات)
  · Reem Kufi (واجهة الأقسام) · Cairo (النصوص الوظيفية) — جميعها `woff2` داخل `assets/fonts`.
- الصور: ثلاث صور مُولَّدة (مكتبة إسلامية ليلية للواجهة، زخرفة عربية للفواصل، صقر للصولة).
- الصوت: **لا ملفات صوتية في المستودع نهائيًّا**؛ الإلقاء يتمّ عبر محرّك النطق المدمج في المتصفّح
  (Web Speech API) — أي لا موسيقى ولا موادّ صوتية محفوظة، والصوت يُولَّد لحظيًّا على جهاز الزائر.

## ٢) هيكل المشروع

```
.
├── index.html                  # الصفحة الكاملة (RTL، بيانات وصفية، sprite أيقونات)
├── assets/
│   ├── css/
│   │   ├── fonts.css           # تعريف الخطوط المُستضافة ذاتيًّا
│   │   ├── tokens.css          # نظام التصميم + النمط الورقي (Design Tokens)
│   │   ├── base.css            # الأساسيات، الخلفية الاحتفالية، الزخارف، الحركات
│   │   ├── components.css      # الترويسة، الواجهة، الفهرس، البطاقات، المشغّل، النوافذ
│   │   └── print.css           # أنماط الطباعة
│   ├── js/
│   │   ├── main.js             # نقطة الدخول والربط
│   │   ├── data/verses.js      # نصوص الأبيات والفصول + التطبيع العربي وواجهة البحث (SSoT)
│   │   ├── render.js           # بناء الفصول والبطاقات، إضاءة البيت، المفضّلة
│   │   ├── card.js             # قالب بطاقة البيت ونصّ المشاركة
│   │   ├── search.js           # البحث الفوري
│   │   ├── quote.js            # صانع بطاقة الاقتباس (Canvas)
│   │   ├── player.js           # مشغّل إلقاء الأبيات (بلا ملفات صوتية)
│   │   ├── speech.js           # محرّك النطق (Web Speech API)
│   │   ├── state.js            # المفضّلة، النمط، مرشّح العرض
│   │   └── util.js             # أدوات: DOM، تخزين، تنبيهات، نسخ، ناقل أحداث
│   ├── fonts/                  # ٢٨ ملف خطّ (woff2): مجموعات عربية + لاتينية
│   └── img/                    # الصور المُولَّدة
└── tools/
    └── build_fonts_css.py      # توليد assets/css/fonts.css من حزم Fontsource
```

## ٣) التشغيل المحلي

```bash
# أي خادم ملفات ثابتة يكفي
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

### اختصارات لوحة المفاتيح
| المفتاح | الوظيفة |
| --- | --- |
| `/` أو `Ctrl/⌘ + K` | فتح البحث الفوري |
| `Esc` | إغلاق النوافذ |
| `Space` | بدء / إيقاف الإلقاء (والمشغّل مفتوح) |
| `J` / `K` | البيت التالي / السابق أثناء الإلقاء |
| `←` / `→` داخل صانع الاقتباس | التنقّل بين الأبيات |

## ٤) الخطوط (إعادة التوليد)

```bash
npm i @fontsource/amiri @fontsource/aref-ruqaa @fontsource/reem-kufi \
      @fontsource/noto-naskh-arabic @fontsource/cairo
# انسخ ملفات woff2 المطلوبة إلى assets/fonts ثم:
python3 tools/build_fonts_css.py --sources node_modules/@fontsource
```
> مهم: كل عائلة مقسّمة إلى مجموعتَي محارف (عربية / لاتينية) بنطاقات `unicode-range`
> الأصلية؛ وبدون ذلك تظهر محارف الترقيم («#»، «—»، ««»») مفقودة في العناوين الذهبية.
>
> ملاحظة: لا تضع أدوات البناء في مجلّد باسم `build/` — فهو مُستثنى من لقطات العمل؛
> المكان الصحيح هو `tools/`.

## ٥) ملاحظات المحتوى

- النصوص مُدرَجة في `assets/js/data/verses.js` **حرفيًّا كما وردت في المصدر**، مع الحفاظ
  على رسم الكلمات الأصلي (مثل: «إيما»، «آسطوا»، «ازلزل»، «الجويهر»، «ارض») ونقله كما هو
  دون تصرّف. البحث يتجاوز هذا الرسم عبر التطبيع، فيجد «الاشعري» البيتَ «الأشعري».
- الفصل الأول يفصل الصدر عن العجز بـ `" ... "` وفق نموذج البيانات، ويُعرض كل شطرٍ في سطرِه
  مع فاصلٍ زخرفي.
- **لا موسيقى ولا ملفات صوتية**: أُزيلت كل الموادّ الصوتية من الموقع بناءً على الطلب؛
  والاستماع الوحيد المتاح هو **إلقاء الأبيات** عبر محرّك النطق في المتصفّح (بلا أيّ ملف)،
  ونبرته تختلف بحسب الأصوات المثبّتة على جهاز الزائر، وإن لم يوجد صوت عربي يستخدم أقرب صوت.
